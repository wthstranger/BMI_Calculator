## 📱 About The Project

**BMI Tracker** is an Android application developed using **Java and XML** in Android Studio.

The application allows users to enter their **height and weight** and calculates their **Body Mass Index (BMI)** instantly.

The goal of this project is to create a simple, clean and easy-to-use BMI calculator while practicing Android application development, UI design and programming logic.

- 🧮 BMI Calculation

## 🧠 BMI Formula

The application calculates BMI using the standard formula:

**BMI = Weight (kg) / Height² (m²)**

### 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | 🟡 Underweight |
| 18.5 – 24.9 | 🟢 Normal Weight |
| 25.0 – 29.9 | 🟠 Overweight |
| 30.0+ | 🔴 Obesity |

> ⚠️ BMI is a general screening measure and should not be considered a complete assessment of health.
